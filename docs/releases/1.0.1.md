# @smoothsdlc/smooth-backlog-cli 1.0.1

The complete branch-aware backlog CLI is published to GitHub Packages. It includes
GUID item identity, active priorities, task and acceptance-criteria lists,
new/open/done/archived states, branch isolation and transfer commands, JSON output,
interactive creation, four agent integrations, and controlled self-updates.

Version 1.0.1 corrects GitHub Packages login guidance for npm 9+ and adds real
published-version upgrade verification to the release workflow.

Requires Node.js 24+, npm, and Git. Authenticate with a GitHub personal access token (classic)
with `read:packages` when npm login requests a password:

```sh
npm config set @smoothsdlc:registry https://npm.pkg.github.com
npm login --scope=@smoothsdlc --auth-type=legacy --registry=https://npm.pkg.github.com
npm install --global @smoothsdlc/smooth-backlog-cli@1.0.1
backlog --version
```
