# backlog-cli

A Git-aware backlog CLI by [SmoothSDLC Systems Inc](https://SmoothSDLC.com),
licensed under [Apache 2.0](LICENSE).

The project is being bootstrapped. The npm CLI has not been implemented;
[initial-prompt.md](initial-prompt.md) contains its requirements.

This repository includes 15 Superpowers skills, six Ponytail skills, a pinned
codebase-memory-mcp setup, and the SmoothSDLC skill-authoring guidance.
Read [AGENTS.md](AGENTS.md) for agent instructions and
[Codex cloud setup](docs/codex-cloud-setup.md) for environment configuration.
